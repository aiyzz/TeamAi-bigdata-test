# 能力 0：数据质量检查

> 所有验证任务必执行。在其他能力之前运行，结果记录到报告中，不阻断后续能力。

---

## 触发条件

所有验证任务必定触发。

## 输入

| 参数 | 必填 | 说明 |
|------|------|------|
| 测试表名 | 是 | 待检查的表 |
| 分区值 | 否 | 如有分区字段则必填 |
| 主键 | 是 | 用于唯一性校验 |
| 维度字段列表 | 是 | 从知识库 DDL 自动提取 |
| 指标字段列表 | 是 | 从知识库 DDL 自动提取 |

## SQL 模板

引用 `templates/common/quality-check-sql.md`（主流程执行）。

---

## 检查项

### 1. 主键校验

| 检查项 | SQL 模板位置 | 预期 | 状态判定 |
|--------|-------------|------|---------|
| 主键空值 | quality-check-sql.md 一.2 | 0 | ❌ > 0 / ✅ = 0 |
| 主键唯一性 | quality-check-sql.md 一.1 | 0 条重复 | ❌ > 0 / ✅ = 0 |

### 2. 维度字段校验

| 检查项 | SQL 模板位置 | 预期 | 状态判定 |
|--------|-------------|------|---------|
| 空值占比 | quality-check-sql.md 一.2 | ≤ 5% | ⚠️ > 5% / ✅ ≤ 5% |
| 维度值分布 TOP 20 | quality-check-sql.md 一.3 | 单值 ≤ 50% | ⚠️ > 50% / ✅ ≤ 50% |
| 枚举值校验 | quality-check-sql.md 一.4 | 全部在预期范围 | ❌ 预期外取值 / ✅ 合规 |

### 3. 指标字段校验

| 检查项 | SQL 模板位置 | 预期 | 状态判定 |
|--------|-------------|------|---------|
| 空值+零值占比 | quality-check-sql.md 二.1 | ≤ 30% | ⚠️ > 30% / ✅ ≤ 30% |
| 统计分布 | quality-check-sql.md 二.2 | MIN ≥ 0（数量金额类） | ❌ MIN < 0 / ✅ MIN ≥ 0 |
| 范围校验 | quality-check-sql.md 二.3 | invalid_cnt = 0 | ❌ > 0 / ✅ = 0 |

---

## 执行步骤

1. 从 `dataware_table/` 知识库读取表结构，提取维度字段列表和指标字段列表
2. 按模板依次执行：
   - 主键空值检查
   - 主键唯一性检查
   - 维度字段空值占比（UNION ALL 批量）
   - 维度值分布 TOP 20（关键维度各一次）
   - 枚举值校验（枚举字段各一次）
   - 指标空值零值占比（UNION ALL 批量）
   - 指标统计分布（UNION ALL 批量）
   - 指标范围校验（数量金额类字段）
3. 汇总结果，按判定标准标记状态

## 输出格式

```markdown
### 1.1 主键校验
| 检查项 | 结果 | 状态 |
|--------|------|------|
| 总记录数 | N | - |
| 主键空值数 | 0 | ✅ |
| 主键重复数 | 0 | ✅ |

### 1.2 维度字段
| 字段 | 总量 | 空值数 | 空值占比 | 状态 |
|------|------|--------|----------|------|

### 1.3 指标字段
| 字段 | MIN | MAX | AVG | 空值+零值占比 | 状态 |
|------|-----|-----|-----|--------------|------|

### 1.4 枚举值校验
| 字段 | 取值 | 数量 | 是否合规 |
|------|------|------|----------|
```
